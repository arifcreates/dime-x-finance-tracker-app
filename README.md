# dime-x-finance-tracker-app

See [backend, AI and subscription setup](docs/AI_AND_BILLING_SETUP.md) for product scope, architecture, configuration and launch requirements.

Run `npm run dev` for development, `npm run build` for type checking and production output, `npm run lint` for lint checks, and `npm test` for automated checks. Copy `.env.example` to `.env.local` and fill the public Supabase configuration first.
